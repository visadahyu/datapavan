隐私政策

这是译文。以英文文本为准。

  • 生效日期： 2026-11-07
  • 负责人： Datapavan 维护者（mehdashti），直至 Visadahyu 基金会成立

Datapavan 不收集任何关于您的数据。

这在实际中意味着什么

  • 没有分析功能，没有崩溃报告，没有遥测。 应用中不含任何可能发送数据的第三方 SDK。
  • 没有账号。 您从不需要注册，也从不需要向我们提供任何东西。
  • 没有接收用户数据的服务器。 应用不联系任何此类服务器。本项目的网站 datapavan.org 是静态网站，不保留访问日志。它也不保留所提供下载的记录。从 GitHub 和应用商店下载适用它们各自的政策。
  • 一切都留在您的手机上。 所有分析都在设备上进行。Datapavan 自己的数据存放在应用私有存储中。
  • 没有备份会离开手机。 对 Datapavan 的数据，Android 云备份和设备间传输均已停用。
  • 卸载会删除 Datapavan 的数据。

Datapavan 在您的手机上保留什么

  • 修复计划的日志。 对于您通过计划所做的每项更改，记录：应用的包名、时间、打开的界面，以及应用在更改前后持有的内容（其敏感权限、特殊权限和 VPN 权限，以及它是否已启用和已安装）。它让您可以撤销更改，并查看某项更改是否又恢复了。在日志界面点按一次即可将其删除。
  • 严格的传感器检查： 您检查时每个应用拥有哪些访问权限。
  • 您的设置： 外观，以及在 Android 13 之前您选择的语言。
  • 跟踪器扫描的结果， 这样未更改的应用就不会被再次扫描；以及您导入的数据包。

所有这些内容都留在应用私有存储中，绝不会被备份或发送。任何能在您已解锁的手机上打开 Datapavan 的人都能看到这些内容，就像能看到应用的其他部分一样。

0.1 版无法打开网络连接

0.1 版（“Audit”）不请求 INTERNET 权限，所以 Android 本身会阻止它打开网络连接。如果任何组件试图添加该权限，构建就会失败。和任何应用一样，在您要求时，它仍然可以把信息交给另一个应用，例如当您打开链接时。

Android 本身的行为不受 Datapavan 控制。在装有 Google 服务的手机上，Play 保护机制可能会向 Google 提供您从任何来源安装的应用（包括 Datapavan）的信息，也可能把未知应用发送给 Google 检查。您可以在 Play 商店的 Play 保护机制设置中关闭其中一部分。

跟踪器列表的可选更新（计划中）

Datapavan 本身只导入已签名的列表文件。如果今后提供可选下载，这些下载将来自公共镜像，而且只有在您开启此功能时才会这样做。和任何下载一样：

  • 镜像的运营者能看到您的 IP 地址和请求时间；
  • 运营者以及任何观察您网络的人，都能判断出该设备在使用 Datapavan。

请求中不包含任何关于您的手机、您的应用或您的活动的内容。更新都经过签名，绝不会接受用旧列表替换新列表。您可以关闭更新，手动导入列表文件。一旦有了镜像，本政策将列出每个运营者，并说明其记录哪些内容以及保留多久。

联系方式

有关本政策的问题：请在 GitHub 上提交 issue。涉及任何敏感内容时，请使用 SECURITY.md 中提到的私下报告表单。
