# 0001. Apache-2.0 licence

- Status: Accepted
- Date: 2026-10-28

## Context
Datapavan must be open source, because a privacy tool that cannot be inspected asks for blind trust.
Stage 3 depends on device makers adopting our engine, and the planned foundation earns part of its
income from certifying their devices. The copyright status of AI-assisted code is uncertain, which
weakens licences that rely on copyright enforcement.

## Decision
License everything under Apache-2.0.

## Consequences
- Device makers and enterprises can adopt the code easily, and the explicit patent grant protects users and contributors.
- Others may build closed products on our code. We accept this. Our protection will be the trademark and the release signing keys, to be held by the foundation once it exists.
- GPL code (for example from NetGuard) can never be copied into the project.
