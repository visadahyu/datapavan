# 0005. Documentation in English only

- Status: Accepted
- Date: 2026-10-28

## Context
The readers of the documentation are contributors, European funders, auditors and partners.
Maintaining parallel translations of the documentation would cost time and drift out of sync.

## Decision
All project documentation is written in English. The app's UI is localised (see 0004); the
documentation is not.

## Consequences
- A single source of truth that every partner can read.
- Non-English speakers rely on the localised UI and on community translations of user-facing guides, if any appear.
