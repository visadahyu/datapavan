# 0014. Permissions for v0.1 "Audit"

- Status: Accepted
- Date: 2026-10-29
- Decided by: mehdashti

## Context
v0.1 audits installed apps without being able to open a network connection. The M2 spike
([2026-10-m2-access.md](../spikes/2026-10-m2-access.md)) showed what a normal app can read on Android 11
and 17. Since Android 11, an app sees only a filtered list of other apps unless it holds
`QUERY_ALL_PACKAGES`. Google Play restricts that permission to a few app types, which include
security apps. Datapavan ships through F-Droid and its own APKs, where no such restriction applies.

## Decision
v0.1 requests exactly these permissions:

- `QUERY_ALL_PACKAGES`: see every installed app. Without it, an audit would be incomplete by design.
- `PACKAGE_USAGE_STATS`: per-app network usage (M4). It is special access that the user grants in Settings; the app works without it and says what is missing.
- `ACCESS_NETWORK_STATE`: tell whether a VPN is active. A normal permission, granted at install, that does not allow any connection.

`INTERNET` stays forbidden, and the build keeps failing if any component adds it.

## Consequences
- The audit is complete, and every check in the M2 milestone is possible without root.
- The "no permissions" statement in the changelog and the privacy policy changes to this list; the privacy policy explains each one.
- If Datapavan is ever published on Google Play, the `QUERY_ALL_PACKAGES` declaration has to be justified there as a security app.
