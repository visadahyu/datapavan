Quand Datapavan a été installé à partir d'un fichier, la carte qui demande l'accès aux données d'utilisation donne désormais, avant ses boutons, les deux étapes pour un interrupteur qu'Android verrouille : essayer une fois, puis choisir « Autoriser les paramètres restreints » dans les infos sur l'appli. Elle nomme ce choix comme le font les paramètres du téléphone lui-même, même quand Datapavan utilise une autre langue.
