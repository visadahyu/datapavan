GotaTun 0.10.3 (https://github.com/mullvad/gotatun) began as a fork of BoringTun
(https://github.com/cloudflare/boringtun). Its README says that contributions made before 5 March 2026 are under
"the old BSD 3-clause license", in a file LICENSE-CLOUDFLARE that its package on crates.io does not carry; 16 of
its source files carry this notice in their headers:

    Copyright (c) 2019 Cloudflare, Inc. All rights reserved.
    SPDX-License-Identifier: BSD-3-Clause

Below the line is LICENSE-CLOUDFLARE, byte for byte, as GotaTun's repository holds it at the tag v0.10.3 (commit
c541472b40ec489ba7bdfd048512e89e556c7a3c; the file's SHA-256 is
6dbef24708bad8c727bd80cca58ba8aa1637cdcb2cc6e9a31ea49235717e9391), taken on 2026-11-20. That day it was compared
with the text this file held before, the SPDX text of BSD-3-Clause with the notice above: the same 224 words in
the same order, only the line breaks differed (ADR 0035, release gate).
